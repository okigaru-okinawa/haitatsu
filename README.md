# 配達ルートアプリ（引き継ぎメモ）

妻（伊良波香織）の薬局配達用。iPhoneのSafariで使うWebアプリ。午前約28件・午後約20件、西原の営業所発着、高速なし。

## 構成
- `web/index.html` … アプリ本体（1ファイル、外部ライブラリなし）。GitHub Pages に置く想定
- `web/manifest.json`, `web/icon-*.png` … ホーム画面追加用
- `apps-script/Code.gs` … スプレッドシート `haitatsu_data`（妻のGoogleアカウント）に紐づくApps Script。ウェブアプリとしてデプロイ
  - スクリプトプロパティ：`API_KEY`（Routes API + Geocoding API のみに制限済み）、`TOKEN`
  - doGet `?a=master` 薬局マスタ取得 / doPost `routes`（computeRoutes代理）`log` `note` `visit` `add`
  - `位置をまとめて取得()` … 緯度経度が空・0の薬局を住所から埋める（初回1回）

## データ（スプレッドシート）
- 薬局マスタ：薬局ID, 名前, フリガナ, 住所, 電話, 緯度, 経度, 駐車_緯度, 駐車_経度, タグ, 備考, 訪問回数, 平均滞在分, 最終訪問日, 追加元
  - 厚労省 医療情報ネット オープンデータ(2026-06-01) 479件 ＋ 九州厚生局 保険薬局指定一覧(2026-10-01)で不足98件を追加（黄色、ID先頭K）。手入力はID先頭U
- 便の記録 / 配達記録 / 変更の記録 … アプリが裏で追記（失敗時は端末に貯めて再送）
  - 配達記録の「午前必着」列は現状「優先（先に行く）」フラグを書いている

## アプリの動き
- 登録：午前/午後を切替、検索（名前・フリガナ・電話、「、」区切りで複数同時＝音声入力向け）、「先に」ピン、新規薬局登録
- ルート：Routes API computeRoutes + optimizeWaypointOrder（TRAFFIC_AWARE、avoidHighways/Tolls）。25件超は直線距離の巡回順で2分割して2回呼ぶ。ピンは順番固定で先頭
- 配達中：次の薬局、最初の曲がり方向、タグ・備考、ナビ開始（Googleマップに渡す）、後回し、ルート変更（現在地から組み直す／先に行く／追加／今日は行かない）
- 自動完了：アプリに戻った時、現在地が配達先から250m以内なら完了。滞在 ≒ 戻った時刻 −（ナビ開始＋区間所要）
- 振り返り：完了した薬局ごとにタグ・備考・駐車位置を保存（マスタへ反映、次回の配達画面に表示）
- 初回設定リンク：`index.html#setup=<base64(JSON{u:URL,t:TOKEN})>`
